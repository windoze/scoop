## 1. 交付范围

已实现内部 TD 查询复用、拆箱／克隆单次对象定位、三个 String 有界表示 intrinsic、按函数 GC effect 选择的 LLVM 优化、普通字段写入的局部 card 查询复用，以及复用现有 worker pool 的并行引用回写。公开 native 输入、精确根、异常、原子和移动 GC 合同保持。默认 nursery 经容量／寿命矩阵比较后保留 1 MiB。

分块 poll、年轻 block 整块退役、metadata 缩减、局部装箱／同步协程包装消除、跨 Cone 内联和声明裁剪仍是设计或实验候选；没有作为生产默认启用。M56 不承诺任意存活堆下的 60 fps，也未引入增量／并发 collector。

## 3. Linux 性能复核

性能使用 GNU，正确性另覆盖 musl。全部构建、正确性验证和临时编译器恢复完成后串行测量；每组一次预热、七次交替独立进程，保留全部样本。输入和结果校验与 PROGRESS 相同。下表默认报告 kernel 中位 [最小, 最大] ms，容量矩阵只列中位。跨平台不直接比较绝对时间，也不把七个进程的统计当作 GC 事件分位数。

宿主为 i7-12700H、14 个物理核／20 个逻辑 CPU、约 61 GiB RAM，Linux 7.0.0-38、LLVM 22.1.2；未改变 `intel_pstate` 的 `powersave` 设置。最终测量开始的 load average 为 2.50／2.27／4.11，可用内存约 39.2 GiB；历史 swap 已占满，但本轮首尾换入／换出计数均未增长。保留共享宿主与动态频率的限制，不能据此宣称专用低配置机器的响应上界。D2 单 worker 固定 CPU 0，四 worker 固定四个不同物理核 0／2／4／6；桌面原型限制在 0／2，其余不固定 affinity。

### 3.3 nursery 取舍

Linux 复核 1／4／16 MiB、1／2 mutator 和三种存活模式，共 18 组；固定 600,000 个 32-byte 节点。计时为分配 kernel 加末尾显式 full 的中位 ms，结果遍历另验证，避免把必要回收移出计时：

| mutator | 保留模式 | 1 MiB | 4 MiB | 16 MiB |
| ---: | --- | ---: | ---: | ---: |
| 1 | 最后一个 | 25.311 | 25.242 | 30.718 |
| 1 | 每 16 个 | 31.728 | 31.609 | 42.852 |
| 1 | 全部 | 118.709 | 104.568 | 60.111 |
| 2 | 最后一个 | 19.544 | 17.286 | 25.082 |
| 2 | 每 16 个 | 26.028 | 27.439 | 35.925 |
| 2 | 全部 | 135.558 | 138.056 | 56.131 |

保留 **1 MiB 默认值**。单 mutator 低存活的进程最大已停稳 pause 中位为 0.494／1.818／6.594 ms，RSS 为 14.2／14.2／28.5 MiB；两 mutator 中存活为 1.432／4.887／11.461 ms，RSS 为 14.2／23.0／36.6 MiB。这是每个进程最大值的中位，包含 full，不是 minor p95。4 MiB 在两 mutator 低存活有有限吞吐收益，不能抵偿普遍加长的暂停；16 MiB 的全存活收益仍涉及跳过 minor、触发 full 的差别。单 mutator 全存活的 1／16 MiB 分别为 17／0 次 minor、均两次 full，copied bytes 为 17,723,696／0，不能归因为单纯 refill 加速。

### 3.4 桌面候选

整块年轻区退役原型在两个物理核限制下，将一千万个短命对象的 kernel 从 283.592→193.156 ms；保留 128 MiB 无引用旧数组时为 299.696→211.656 ms，RSS 基本相同。全部为零复制负载，没有进入这次修正的引用回写路径，沿用同一对原型产物复测。完整区间、暂停口径与限制见[桌面补充 5.2](DESKTOP-GC.md#52-linux-两核限制复核)。原型仍不作为生产默认，也不替代真实 GUI 帧率、混合寿命和低配置实机验收。
