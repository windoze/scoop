# 条件引用读取的部分展开

以 `f9ccfab7e` 为基线，扩展[单块引用读取展开](REFERENCE-UNROLL.md)，使已有 `sumOptional` 的空值分支也能进入四倍展开。三个现有目标均为 release 默认能力，不增加公开开关或等级。

## 设计与范围

先修订实现规范 2.19，再扩展现有选择器。接受最多四个无环块、所有路径到达同一 latch、4～64 次且可被四整除的只读内层；正文总计最多 24 条非 phi／分支指令，必须包含从 AS1 对象读取 AS1 引用。新增引用相等／不等判断及条件标量合流，继续使用原区域分析和 LLVM 固定展开提示。

- 每个元素保留自己的空值 guard；原空值路径不执行的字段读取不会变成无条件读取。严格浮点归约仍按原顺序累加。
- 保留原 64 次分块、短尾、外层 poll 和根恢复；引用及派生地址不逸出内层，不提升普通根加载。写入、调用、原子／volatile、提前退出、内环与引用递推仍排除。
- MIR／LIR、接口父表投影、对象布局、GC 与 `.slib` ABI 均不变，不增加引用 SIMD、动态判断或新的运行时机制。

## 定向验证

两机最终格式化、workspace Clippy 和各 19 项有界循环后端测试通过。新增条件读取、每项 null guard、条件浮点累加顺序，以及仅在非空分支发生写入／调用的拒绝路径；复用三个目标的 LLVM safepoint verifier、两个原 safepoint、单根恢复及真实对象／stackmap 发射检查。

[引用数组优化合同](../../tests/fixtures/compiler-correctness/optimization/lowering/reference-arrays/fixture.toml)和[引用数组根与屏障](../../tests/fixtures/gc-correctness/poll/reference-arrays/fixture.toml)在每个目标通过两组 fixture、三个变体、13 次进程调用，覆盖 debug／release、短尾、边界、接口／装箱／wrapper 及并发 moving／minor。没有全量验收，也未重建未变化的系统库。

三目标最终程序、根 `.slib` 和 LIR 与已测四倍候选逐字节相同，复用其运行和 GC 数据。基线／候选的 19 种模式输出、完整 LIR、242 条 TD／接口表／布局定义与原 poll／live 集合保持；27 种负载各 15 项分配、GC、脏卡及扫描计数相同。伪随机输入以种子 7 的 32-bit LCG 高位选择，计时前构造；独立计算确认长度 256 时有 127 个 Some，输出差值符合实际元素贡献。

真实 `sumOptional` 每四项共同维护一次内层计数，各字段读取仍由对应空值分支保护。完整函数的机器指令数从 ARM64 82→98、x86 92→117；检查的另外 15 个函数指令数量保持，原短尾保留。

## 收益与取舍

两版工具使用同一[引用数组基准](../../tests/benchmarks/arrays/references)、预编译 core／runtime 和输入。机器为 M3 Ultra／LLVM 22.1.8、nuc12 i7-12700H／LLVM 22.1.2；Linux 固定 CPU 4。新增全 None、全 Some 和固定伪随机分布，初始化不计入读取内核时间。

普通 128 轮、短路径 10 万轮先做一对预热、七对 AB／BA，GC 另行收集。为减少短阶段波动，再将临时源码中的长路径轮数改为 4096，以 65,536 个元素、两对预热和 11 对 AB／BA 测量；下表为较长内核墙钟中位数变化，负数表示降低。

| 分布／操作 | Darwin ARM64 | Linux GNU | Linux musl |
| --- | ---: | ---: | ---: |
| 交替 Some／None | −51.15% | −29.37% | −15.15% |
| 全 None | −0.19% | −22.58% | −24.64% |
| 全 Some | −7.63% | +1.59% | +1.37% |
| 固定伪随机混合 | −38.08% | −4.18% | −3.48% |
| Node 字段求和对照 | +1.30% | −0.60% | −0.38% |
| 末项身份搜索对照 | −0.15% | −0.20% | −0.66% |
| Long 求和对照 | +0.05% | −0.04% | +0.09% |

Linux 全 Some 的小幅回退保留为已知成本，普通 128 轮同样为 +2.80%／+1.63%。两倍条件展开试验未改善该路径：在四倍／两倍预构建程序的直接交错比较中，两倍对交替、全空、全有值的配对耗时增加 2.77%～11.39%；随机混合为 GNU +1.03%、musl −0.10%。因此保留统一四倍策略，未提交二倍目标分支。

普通组 GNU 清零／String 复制对照分别为 +4.43%／+3.24%，指令数量没有变化；这些差值不归为本项收益。八类短路径最大绝对回退为 ARM64 0.150 ns／调用、GNU 0.008 ns／调用、musl 0.226 ns／调用。测量描述当前机器和分布，不代表已完成通用应用或跨语言性能验收。
