# 程序性能优化实施记录

本轮从 `de5f4609b` 开始，工作分支为 `codex/program-performance`。范围与取舍以[调研报告](INVESTIGATION.md)为依据：测量能力提前独立交付，持续改进编译器、runtime 与库；PGO 后续按实际消费者和收益安排。

## 交付约定

- 每项功能完成必要验证后单独提交、推送，再获取并合并 `origin/main` 的更新。实验实现留在本地或临时实验分支，只有形成可交付结论的实现进入推送分支。
- 成本低且收益稳定的优化进入 release 默认设置；高成本或收益不稳定的方案通过实际需要的开关或等级提供，保留默认 release 对照。
- 临时源码、构建、测量及原始日志统一放本仓库忽略的 `tmp/program-performance`；定期检查并清理已无用途的 target 产物，保留仍需复用的构建缓存。
- 每项改动只运行一组足以证实其正确性的定向验证；先完成本机验证，涉及平台合同再在 `nuc12:~/repos/scoop` 补相应 Linux 组合，不默认运行完整验收。只有新增失败或合并影响要求时才扩大范围。

## A1：可复现的预构建程序对照

- [compare.py](../../tests/benchmarks/compare.py) 串行执行 AB／BA 对照，预热样本单列；支持已知 stdout、相同输入参数、双方独立环境覆盖和可选 GC 诊断。CPU 与峰值 RSS 来自每次子进程的资源统计，原始输出及样本保存在指定工作目录。
- 默认清除继承的 GC stress／full-only／统计设置。失败、输出不一致或 GC 记录错误会停止测量并保留原始文件，不发布成功报告；报告只记录显式环境覆盖，不保存整个继承环境。
- GC 记录解析由新旧测量入口共用，保留现有 `measure.py` 的输出结构及 nursery／full-only 对照。中位数与比值为描述统计，未将其当成显著性判断或应用内部稳态／尾延迟。
- 本机与 Linux 各通过 10 项测量工具测试和 55 项 fixture runner 公共测试；固定版本 Ruff 格式与 lint 通过。Darwin ARM64、Linux GNU／musl 分别以实际 primitive／allocation 程序核对正常退出、已知输出、进程资源、GC 记录、full-only 控制和旧测量入口兼容性。
- 实际程序验证消费各机现有 release 工具与预编译 sysroot；本项交付测量能力，不包含编译器／runtime 改动或性能提升声明。原始记录位于两机的 `tmp/program-performance/a1-*`。

## B1：完整父接口表投影与视图复用

- 所有 profile 使用完整内嵌父表：单继承前缀直接复用，其他已知父视图只作固定指针调整；菱形保留完整父片段，TD 目录复用这些片段。跨 Cone／`.slib` 的 layout/ABI capability 升至 `/17`，相关旧产物重建。
- 继承调用按真实方法身份和完整 ABI 使用 Child 物理槽；release 保留 smartcast 已取得的 Child 视图，并仅缓存 GC-free itab，避免增加对象存活或根。Any 首次取表、无静态父关系的转换和必要 ABI 恢复继续按原语义处理。
- 三个目标的 IR／机器码确认适用的上转型与继承调用不再产生 `itable_lookup`。五个接口热点模式的进程耗时中位数下降：Darwin 6.60%～28.98%，GNU 20.43%～39.75%，musl 14.90%～46.54%。完整基准程序非空表槽从 667 降至 547；实际标准库集合层次也减少表空间。代表性 provider 编译耗时基本持平，峰值 RSS 增加 0.33%～1.32%。
- 相关 Rust 测试、跨 Cone 反向 profile 与独立链接、泛型／装箱／default／adapter、定向 GC 组合通过。同步修正既有条件接口 ODR fixture 的过时依赖数，三个目标均闭合。按用户要求停止已启动的 GNU 完整 CLI 批次，后续不默认运行全量验收。静态投影与布局作为默认能力，块内动态复用默认用于 release；本项不引入额外布局模式或 PGO。

## B1：接口检查与取表合并

- 新增 NoGC `itable_find`，返回不可变目录项或 null；空接口匹配与 null slots 明确区分。runtime ABI contract 升至 15，metadata ABI 9、父表布局 capability 17 及接口值双字表示保持。
- release 在有非空接口视图消费者时融合检查，覆盖否定条件的 Boolean 临时值和 `as`／`as?`；只保存 metadata。普通 CFG 上复用同一未取址局部值的成功检查，写入／不共同的合流／异常入口失效；对象跨 GC 移动后继续使用当前 managed 引用。
- 本机 31 项相关 Rust／C 测试及三目标各三组正式 CLI 专测通过，未运行全量测试。真实源码与机器码确认 smartcast 热点从一次 is 加一次 lookup 降为一次 find，已有父表投影与继承调用仍零查询。
- 相对父表投影版，两个热点的耗时中位数下降：Darwin 5.95%／28.20%，GNU 26.15%／28.53%，musl 23.07%／25.64%。表存储完全不变，完整程序增加 40～48 bytes，provider 编译墙钟差异 −0.90%～+1.43%。静态调用对照变慢 0.45%／0.71%／4.51%；musl 已确认指令不变而位置变化，保留回退和后续布局归因工作，不将其报告为普遍收益。
- 该能力默认用于 release，不新增优化等级或 runtime 缓存。后续测量与静态优化继续独立于 PGO。

## B1：普通 class 与局部游标字段替换

- 扩展既有 box／closure 来源、支配和循环分析，登记无 release hook 的 declared ClassAlloc，包含构造器展开后的 Assign。可替换字段读写使用同一 typed local，原值复制与构造副作用保留；基类采用已确定的 flattened 字段布局。公开 ABI 和对象／接口表示不变。
- 本机 22 项相关 Rust 测试及三目标各两组正式优化／GC fixture 通过；没有全量验收。IR／机器码确认 Point／Cursor 每处 1 次分配、4 次字段读和 3 次字段写均消失，循环 poll 保留。泛型聚合字段、接口引用和构造中间 GC 的精确根已核对。
- 七对 AB／BA 中，Point 整程序耗时降低 74.69%～83.13%，Cursor 降低 13.06%～15.61%；内核时间分别降低 85.65%～89.46% 和 17.93%～19.80%。对应负载减少 320 MB／64 MB 分配，minor 306／61 次均降为 0。真实 ArrayList 未命中，保留 GNU 进程 +2.27%、内核 +1.64% 的实测回退。
- 编译墙钟差异 −0.33%～+2.27%，完整二进制减少 600～704 bytes，TD／类型布局记录不变。该能力沿用 release 默认分配消除，不新增等级；真实库 next 的内联由下一项继续处理，跨调用和部分逃逸仍有后续工作，不能将本项视为全部 class／iterator 消除完成。
- 收尾修正六组 GC fixture 与 minor-mark 基准的压力循环，显式发布短命对象并在下一次分配前清空测试槽，避免对象被优化后永远等待 minor GC。本机六组定向验证、GNU／musl 的代表 gc-writes 组合及三目标 minor-mark 冒烟通过；未扩大为完整验收。

## B1：局部对象字段替换指导内联

- 复用已有分配／别名／支配／循环证明，只为最后一个 receiver 调用共同计算内联与字段替换的净成本；原操作、复制和冷分支权重共用，全局阈值与累计增长保持，最少扣减一单位增长，不按类型名字特判。
- 真实 ArrayList 基准的 ListIterator 分配与 next 调用消失，size 被展开、get 成为直接调用。三目标七对 AB／BA 中整程序降低 29.98%～36.20%，内核降低 41.18%～42.01%；50 万次遍历减少 24 MB 分配，minor 22→0。
- 本机 47 项 MIR 优化测试与三目标各两组正式专测通过，包含继承／循环／外来合流、未知调用／身份／取址，以及 struct／tuple／String／接口引用的 moving／minor 组合。最终 GC 用例已通过 MIR 确认真正消除 iterator；只重跑发生调整的用例，没有全量验收。
- 完整程序减少 304～352 bytes，81 条 TD／布局记录相同；编译墙钟 −1.24%～−0.08%，峰值 RSS +0.18%～+1.26%。三个未改变的对照内核保留正负小幅波动。该优化沿用 release 默认设置，尚未展开的创建、多个 receiver 调用、逃逸／EH 和净成本过高的情况继续保留。

## B2：有界整数／Boolean 数组初始化

- 本机 5 项 MIR／3 项代码生成测试及三目标各两组正式 CLI 专测通过，覆盖 debug／release、分块边界、回绕／异常／越界前缀、引用保留路径和 moving／minor GC。补充重赋临时值快照的回归并收紧归纳变量证明；无间隔 GC 请求的测试超时在基线也复现，加入 NativeSafe 请求间隔后闭合。只重跑受影响用例，没有全量验收。

## B2：普通数组访问的检查消除与分块

- 从 typed 数组引用、稳定上界与归纳变量建立范围事实，按语句次序保存快照；同数组长度直接去除不可达检查，显式 count／其他数组通过长度 guard 选择 64 次完整块，条件失败与短尾继续执行原 checked 正文。复用既有支配分析，覆盖真实内联到外层循环的数组访问，保留求值顺序、异常前缀、poll／roots 和全部 ABI。
- 本机 5 项既有 MIR 回归与三目标各两组 CLI 优化／GC 专测通过，每目标 3 个 variant、12 次进程调用，没有全量验收。首次测量发现内联复制未命中，修正支配识别后完成受影响验证；错误假设所有 getter 均已展开的测量断言也已据实际产物纠正，保留未命中对照。
- 相对 `c4390283f`，七对 AB／BA 的大数组求和／变换／复制／同数组复制内核分别降低 Darwin 66.48%／92.84%／78.60%／66.41%，GNU 43.51%／80.77%／53.17%／77.44%，musl 37.48%／78.92%／46.36%／77.26%。综合求和因 getter 增长成本 35 超过剩余 24 而保留调用，实际内核基本不变；没有提高全局阈值。

## B1／B2：循环范围指导数组访问内联
