# 普通 String 拼接进入生成路径

基线为 `41e9a72d9`。release 在 MIR 内联之后融合同块、单用的拼接结果，保留求值顺序；其他调用、可变写入、取址来源及控制流边界结束分析。最多八个片段，相邻短常量合并至 64 bytes。原输入可以重复使用，中间结果被其他位置使用时仍保留其分配。普通二元拼接在现有静态热度判定的循环或全部输入为短常量时使用同一路径，普通冷点共享 runtime。

MIR／LIR 的 typed StringConcat 操作携带真实 String TD、已求值输入和常量 bytes。生成代码 checked 累计长度，复用 TLAB 与 collecting slow path，一次分配、写长度并按序复制；分配后重读移动输入，不跨 safepoint 保存内部地址。常量片段不生成额外 immortal 或 GC root。旧二元 C ABI、String 布局、`.slib` 格式和 debug 行为保持；StringBuilder、插值和数值融合没有改动。

本机及 NUC12 完成相关 Rust 格式化／Clippy；三目标各两项 core Cone 测试、两个 profile 的 IR／moving fixture 通过。覆盖 Unicode、NUL、空串、左右嵌套、共享结果、可变输入快照、调用顺序／异常前缀及超过普通 Immix 对象上限的结果。最终 MIR 与机器码确认目标循环无 `scoop_rt_string_concat`，五段链只保留一次分配与输入复制；普通共享结果函数仍有两次二元后备。Linux 验证 snapshot 缺少既有 include_str fixture 的准备问题已补齐，未改编译器处理规则。

以下为一次预热、三对 AB／BA、每轮一百万次的中位数 ns／次；输入构造和输出在计时区间外，旧 → 新：

| 用例 | Darwin ARM64 | GNU x86-64 | musl x86-64 |
| --- | ---: | ---: | ---: |
| 热二元 | 32.910 → 13.806 | 35.763 → 13.486 | 45.088 → 26.271 |
| 五段链 | 137.821 → 14.100 | 131.088 → 10.585 | 292.879 → 50.944 |
| 共享中间结果，两次分配 | 67.116 → 26.367 | 70.306 → 21.351 | 130.676 → 88.536 |
| 全常量链 | 103.854 → 3.214 | 95.875 → 5.661 | 240.144 → 5.766 |

仅融合链的本机对照中，未改变的热二元为 32.622 → 32.531 ns；进一步展开热二元后形成上表收益，采用调用点范围，没有无条件展开所有二元调用。常量链仍分配结果，此项不实现 builder 消除或通用 String 常量池。

十万次的分配字节数三平台一致：热二元 4,800,176 B 不变，五段链 17,600,176 → 4,800,176 B，共享中间结果 11,200,176 B 不变，全常量链 11,200,176 → 4,000,176 B。五段链分配次数由 IR 的四次变一次，minor 16→4；常量链三次变一次，minor 10→3。176 B 为输入构造／启动及结果输出。没有向普通产物加入计时或计数代码。

三个目标 text 分别增加 1,096／1,024／1,024 B，完整文件减少 17,536／4,800／4,800 B；core 库及 runtime 使用相同预编译输入。三对独立冷 consumer 编译墙钟变化 +2.25%／−2.95%／−1.42%，CPU −1.84%／−3.01%／−1.28%，峰值 RSS −0.19%／+0.02%／约 0%。一轮误复用旧 baseline cache 的编译数据已排除，重新使用双方新的 cache／输出路径。

能力为 release 默认，无新增公开开关；更长链按实际可融合片段处理，跨副作用边界与无法证明的来源保留后备。原始记录、IR 和机器码在仓库外 `scoop-performance-results/2026-10-26/runtime-visible/string-concat`，构建与对照工具在 `tmp/program-performance/string-concat`；可复现源码为 `tests/benchmarks/scalars/concat.scoop`。
