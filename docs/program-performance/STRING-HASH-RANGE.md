# String hash 有界范围与提前返回

基线为 `3ca709194`。最新 strmap 的一次主线程采样中，coreStringHash 及下游占 758／3558 个样本，其中 native 进入／退出和 caller roots 对应的调用位置占 527 个样本。该采样只用于选题，不把样本比例换算成收益；原 String hash 只在至多 8 B 时使用普通 core 正文。

本项将普通正文扩大到 32 B，每处理完实际输入就直接返回。逐字节读取和 FNV-1a 的 xor／ULong 乘法直接写在 core 中，复用已有 typed byteAt、调用点内联和常量传播；保持原初值、无符号字节扩展及 64-bit 回绕结果。9～32 B 路径省去 push roots、进入 NativeBorrowed、C hash、离开 NativeBorrowed、pop roots 五个调用及其协调工作。动态点仍可共享 core callable，入口 poll 和实际需要的根保持。大于 32 B 直接使用原 native 后备，不重复扫描前缀。

对照过原式分别展开至 16／32 B、普通循环至 64 B，以及提前返回至 16／32 B。直接扩展原来的独立 if 会让极短输入经过更多空判断，ARM64 的 8 B 从约 2.23 ns 增到 4.20／8.34 ns；循环版在 9 B 约 5.93 ns。提前返回的 32 B 版覆盖更宽的获益区间，静态增量较小，予以采用。旧 scalar helper 的边界不再留下局部未内联调用；没有新增 intrinsic、编译器名字特判、runtime 符号或布局。

两机格式化／release Clippy 通过。三目标各通过 3 项 core 读操作测试、1 项 HashMap API 测试，以及 debug／release 两变体的编译器专测。覆盖长度边界、NUL／多字节 UTF-8、固定旧 hash、接口与方法引用、跨 Cone、搬迁后读取；IR 固定十六字节常量热调用点消除 hash 调用，原三字节常量回归保持。旧 fixture 分配量不足以触发 minor，已补真实分配压力并分开 moving／minor 变体：各目标 debug 实际 121 次 full、复制 14,016 B；release 实际 5 次 minor、5 次 full、复制 120 B。没有运行全量验收。

正常 release，一次预热、五对 AB／BA，动态点交替使用两个不同字符串。输入在计时前构造，短输入每轮两百万次，4096 B 为三万次。三目标两侧的四种 runtime 资源各 92 个对象逐字节相同。下面为 ns／次中位数，strmap 单列整程序毫秒：

strmap 降低 16.97%／12.81%／10.17%。GNU 极短输入初测回退明显，正文与 musl 相同，地址生成及链接位置不同；另固定 P 核 CPU 4、每轮一千万次、五对交替复核：1 B 为 2.093→1.508 ns，7 B 为 2.574→2.387 ns，8 B 为 2.622→2.629 ns，9 B 为 17.797→2.893 ns。musl 对应 8 B 为 2.614→2.643 ns。初测与复核均保留，不把未固定 CPU 的极短测量差值解释为算法固定成本。ARM64 的 8 B 增加约 0.49 ns、33 B 增加 2.96% 仍是本次取舍；128／4096 B 后备的变化保持在 −1.70%～+0.80% 范围。32 B 常量热调用点仍共享 hash 正文，尚未完全折叠。

未修改的 dispatch／lambdas 两侧 MIR、LIR 逐字节相同。实际最内层分派循环的 fast-path 栈访存仍分别为 ARM64 2／2、x86_64 3／5 条，含 poll 慢边为 4／4、5／9 条。dispatch 整程序变化 −2.30%／+1.55%／+0.52%，lambdas 为 +2.76%／+1.00%／+0.69%；不把这些变化计作本项收益，也未仅凭 IR 相同排除链接布局等成本。

所有 hash 长度、strmap、dispatch、lambdas 的分配字节、minor／full 次数、复制字节及根扫描计数旧新相同。hash 正文本身不分配；strmap 均分配 777,411,704 B，259 次 minor、9 次 full，复制 12,695,360 B、扫描 18,672 个 root slots。上述计数另行运行，未混入计时。

采用普通 core 算法作为所有 profile 的默认正文；release 按原调用点评分展开。需重建 core 及其依赖者，runtime contract 19、metadata 9 和 String 表示均保持。不开新优化开关，不新增程序诊断代码；phase helper 只由专用基准显式链接。长字符串、一般动态调用、入口 poll 和仍必要的 GC／ABI 存储保留。
