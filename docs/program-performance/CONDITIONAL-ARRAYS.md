# 含条件分支的数组循环

## 依据与布局

基线 `33aa72f0d` 的四个代表内核——条件求和、双分支变换、条件写入和浮点限幅——已经展开数组访问，但均因数据相关的分支保留逐轮 poll。仅支持直线正文使普通筛选、条件变换无法复用现有范围证明与 SIMD。

本项继续使用 64 次分块，接受单入口、单 latch 的无环正文。归纳变量仍从非负值开始、严格小于稳定上界并每轮唯一加一；该更新必须支配 latch。保留实际分支，不将条件写入或另一分支的读取提前。循环内部再循环、提前退出、多回边、未能消除的调用与异常沿原路径执行。

当前位置的标量与数组范围事实沿拓扑次序传播，合流只保留所有到达路径共同成立的事实。分支后的索引快照不能借用另一分支的赋值；长度 guard 取并集，只引用入口已可用的稳定数组。无 guard 时直接删除已证实不可达的检查；需要 guard 时只复制满足条件的正文，长度不足仍执行原有 checked 路径并保留异常前缀。

完整内层复制实际 CFG，内部临时 local 和块边一起映射；循环携带值保持原 local。原 poll、managed 基址恢复和最终精确 roots 保持，不新增对象、持久 IR 字段、runtime 或公开 ABI。所有 profile 遵守同一语言与表示合同。

LLVM 选择同样检查实际单入口、单 latch、内部无环的区域及常数倒计数。只允许现有标量操作和普通数组访存，只有根槽的普通稳定加载可以移至内层入口；条件元素访存交由 LLVM 按原条件合法优化。原子、volatile、根写入、指针合流与未知调用继续排除。严格浮点不增加 fast-math、重结合或乘加融合。

## 机器布局与回退闭合

初次测量中，musl 直线求和对照回退约 76%。独立函数的 LIR 与有效指令不变，但实际计时路径已经内联到 `exercise`；因此不能只检查独立定义。固定到 NUC12 的 CPU 4 后，回退仍存在。

在未改变数据地址、调用点、函数边界和计算的临时二进制副本中，将实际 19 字节内层提前 6 字节，使它完整落入同一个 32 字节块，内核从 1.883 ms 恢复到 1.071 ms。仍跨界的 2 字节平移没有恢复。Linux 的硬件性能计数器不可用，归因限于这组位置控制实验，不声称已测量某项微架构事件。

仅启用 LLVM 的条件分支对齐会在热内层中插入 NOP，未能稳定解决问题；该实验未交付。实际采用 LLVM 22.1 的 `x86-experimental-pref-innermost-loop-alignment=5`，让 x86 release 最内层优先从 32 字节边界开始，填充放在入口之前。使用 LLVM 既有机器循环选择，不匹配基准或函数名称，不强制对齐所有基本块，不增加用户开关。对象分区、链接与 stackmap 保留 LLVM 最终布局。

最终 GNU／musl 链接程序中，该内联内层均为完整 19 字节、入口模 32 为零且无内部填充。九对固定核 A/B 的直线求和变化分别为 −0.20%／−0.32%，整进程 +0.13%／+0.05%；原大幅回退已闭合。相对仅增加条件分块的版本，入口对齐额外增加 text 448／512 bytes、根 `.slib` 各 378 bytes，完整程序文件大小不变。Darwin 的 LIR、`.slib` 与完整程序逐字节不变。

## 验证与实际生成代码

- 本机 56 项 MIR 优化回归、8 项后端回归通过；Linux 同组 8 项后端回归通过。后端回归包括实际分支区域、内部循环／提前退出／根写入拒绝、严格浮点、三个目标的机器调用点，以及 x86 短内层入口布局。
- 三目标各通过两组正式优化／GC fixture，每目标 3 个变体、12 次进程调用。覆盖 debug／release、0／1／63／64／65／129／1025 元素、单边／双边条件、别名、未选分支的短数组、索引快照、异常前缀、NaN／signed zero／subnormal／Infinity 及严格累加；两 mutator 的 moving／minor 组合也通过。
- 8 个新增代表内核均由 0 个完整块变为 1 个，保留真实分支与原 LIR poll；提前退出搜索仍保留原循环。12 个函数的 poll live 集合及 161 条 TD／接口表／布局记录保持。
- 整数条件求和与双分支变换实际生成 SIMD：Darwin 包含向量比较、掩码与加法，Linux 使用 SSE2 整数运算。Float／Double 限幅与掩码 Double 求和仍是标量内层，收益来自分块及检查整理；未出现浮点重排或 FMA，不能将所有收益归于 SIMD。
- 21 种负载的分配、nursery、minor／full、晋升／复制、root slots、traced objects 与 remembered-set 计数 A/B 一致。含分配的大数组初始化两版都分配 37,555,576 bytes、执行 3 次 full GC、扫描 141 个 root slots。

没有运行完整验收。布局策略调整后只复测受影响的后端、Linux 同组 fixture 与基准；Darwin 根据产物逐字节一致复用已有运行验证。原始源码、日志、IR、机器码、样本及未交付实验保留在忽略的 `tmp/program-performance/conditional-arrays`。

## 运行结果与成本

相对 `33aa72f0d`，使用 [conditional 基准](../../tests/benchmarks/arrays/conditional/README.md)，复用预编译 sysroot。大数组为 65,536 元素、128 轮，单元素为 100,000 轮。每组一次预热、五对 AB／BA，运行与 GC 诊断分开；Linux 最终测量固定 CPU 4，布局对照额外使用两次预热、九对 AB／BA。数组准备在计时区外，`initialize` 明确包含分配。以下为内核耗时中位数变化，负值表示更快，不作为统计显著性声明。

| 内核 | Darwin ARM64 | Linux GNU | Linux musl |
| --- | ---: | ---: | ---: |
| 条件 Long 求和 | −68.92% | −35.21% | −33.44% |
| 双分支 Int 变换 | −92.71% | −79.51% | −79.36% |
| 条件写入 | −75.77% | −43.90% | −49.62% |
| Float 限幅 | −54.31% | −28.23% | −29.29% |
| Double 限幅 | −56.78% | −26.23% | −27.98% |
| 掩码 Double 求和 | −56.22% | −45.87% | −44.90% |
| 按条件写入两个目标 | −70.83% | −12.04% | −15.78% |
| 条件初始化，含分配 | −76.30% | −40.31% | −29.53% |

上述 8 种负载的整进程耗时降低 4.51%～38.18%；进程结果包括启动与数组准备，不能用内核降幅替代。全命中／全不命中的条件求和降低 31.14%～67.87%，两个固定分支方向的变换降低 77.79%～92.79%；源目标相同的变换降低 45.45%～67.19%。

短路径仍有成本：五种单元素内核变化为 −13.05%～+24.95%，最大相对回退是 musl 条件求和，0.510→0.637 ms，约 +1.27 ns／遍历；最大绝对回退是 Darwin 初始化，约 +1.33 ns／数组。它们的整进程最大回退为 1.57%。提前退出搜索没有分块收益；五对测量为 +0.05%／+2.91%／+0.35%，额外九对 Linux 对照为 +7.29%／+1.92%，这些回退继续保留。

GNU 无 GC 对照在一轮批次中，双方中段都由约 10.8 ms 升到约 13.4 ms；分别取中位数得到内核 +24.05%、整进程 +19.25%。原样本保留，单独九对复测为内核 +0.0024%、整进程 +0.24%；先前九对也接近零。该批次扰动不能当作稳定的编译器回退或收益。Darwin／musl 的同一对照内核分别为 −0.02%／−0.14%。

编译同样采用一次预热、五对 AB／BA。静态表语义记录保持，不代表全部机器 metadata 字节不变：Darwin stackmap 增加 760 bytes，GNU／musl 的 Scoop metadata section 各增加 2,616 bytes。完整程序空间和编译成本包含这些增量。

该有限范围作为 release 默认能力，保留 64 次上限及既有内联阈值。没有额外布局框架、公开 ABI 或 PGO 依赖；一般 CFG、提前退出、未知调用、引用／聚合元素、有序归约 SIMD 和短路径选择仍需分别处理。收尾清理本机 81 份旧增量会话，释放约 1.29 GiB，保留各 crate 最新缓存。
