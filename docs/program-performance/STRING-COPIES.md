# String 字节复制与 Char 编码

基线为 `4c7c771d6`，已包含接口复制传播、根恢复精化、晚期 aggregate 分解及末尾无用 relocation 修复。两边固定相同源码、接口布局和 runtime 文件，分别重建配套 core／std／test／json；本项没有 runtime C 改动。运行测量使用普通 release，GC 统计与 stress 分开执行。

新增五个真实 typed String intrinsic，经 MIR StringCopy 和完整 LIR 布局生成一次分配、长度写入及精确 memcpy：稳定原生 UTF-8 缓冲到 String、已定位字节范围切片、exact Byte 数组到 String，以及 String 到独立 Array／MutableArray<Byte>。后两项原来仍有逐字节 initializer 循环，最终机器码确认其已消失。复用已有 TLAB／慢路径和根计划；托管源在分配后重取引用才计算内部地址，即使源码调用后已死，也保留展开后的复制所需恢复。无引用 payload 不增加写屏障。

Char 的 1～4 B UTF-8 编码改为普通 core 正文，写入四字节 GC-free 栈缓冲后复制。整数编码也复用新复制路径，十进制算法不变，不重复计算前一批替换 printf 的收益。补齐普通方法／getter application 的可移植正文引用，以及保存 exact Char owner 的常量事实；不按函数名改变合法性或收益阈值。实际调用点评分中，动态编码净增长 182、惩罚约 232、热度加权收益 96，保留共享 helper；`'A'`／`'雪'` 在 code getter 化简后净增长 28／75、惩罚 32／90、收益 144／240，选择内联。三目标常量探针均消除 helper 和动态 memcpy，保留分配与固定字节写入。

两机格式化／Clippy 和 41 项定向 Rust 测试通过，覆盖 intrinsic wire／签名、普通方法正文、Char 常量边界、调用点选择及复制后的根使用。三目标各 7 项 core 行为测试、debug／release moving fixture 通过，覆盖 NUL、Unicode 标量边界、空数组独立存储、修改快照、自定义 List getter 次数／顺序／异常，以及旧 extern ABI。stress 实际复制 264,664／237,800 B；旧 `char_to_string`／`string_from_bytes`／`string_slice_bytes` 外部调用仍在专测机器码中，未被符号拼写替换。没有全量验收。

Linux dispatch 初测回退 16.30%／15.30%。GNU 的真实内层仍是同一 35 条指令、全区域 5／快路径 3 条栈访存，四个 area 正文也保持，代码地址改变；未发现新的复制、根恢复或内联回退。固定 CPU 4 的五对复核为 GNU 0.435278 → 0.493066 s、musl 0.439170 → 0.437925 s，逐对差异较大。同一 GNU 候选二进制的五对自对照中位数差 −0.44%，单次 0.433～0.449 s。保留初测与复核，不能据此排除 GNU 的布局回退，也不将这部分变化归因为 String 算法或接口 SSA；本项没有按函数加 padding 或另改分派策略。

动态十模式程序 text 减少 140／384／384 B，完整文件减少 6,528／11,288／11,288 B。单独常量探针的 text 增加 1,044／768／704 B，这是兑现常量内联的实际空间成本。core.slib 增加 148,496／138,678／144,420 B；四库合计增加 0.911%／0.821%／0.797%，包含可移植方法正文的增加。三对独立冷 consumer 编译墙钟增加 0.56%／0.86%／1.72%，CPU 增加 1.69%／0.81%／1.85%，峰值 RSS 增加 5.65%／1.41%／1.36%。四库单次构建总墙钟为 34.94→31.60／43.77→39.25／41.73→39.64 s，仅作成本记录，不视为稳定编译加速。

新 core 协议在所有 profile 一致；release 默认按已有调用点评分展开并复用 TLAB，动态／较长 memcpy 保留共享实现。旧 C ABI、String／数组布局和 `.slib` 容器格式保持，配套 core 及依赖须常规重建；未增加公开开关、测量代码或对象字段。标量范围定位、普通 List 快照、from_chars、严格／lossy UTF-8 和分配慢路径继续复用原实现。StringBuilder、Float／Double、初始化就绪检查与 Context 不属于本批改动。

原始测量、首个复制候选、方法正文候选、最终 IR／机器码及 dispatch 复核在仓库外 `scoop-performance-results/2026-10-26/string-copies`，ARM64 在本机，GNU／musl 在 nuc12；构建与测量输入保留于忽略的 `tmp/program-performance/string-copies`。
