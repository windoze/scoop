# MaybeUninit 的整字原始存储

`MaybeUninit<T>` 原来把非引用区间表示成 LLVM 字节数组。普通数组读取及 `assumeInit()` 经过 SROA 后会暴露逐字节组合，LLVM 向量化因而生成大量字节 gather、重排和寄存器溢出；扩大内联额度不能解决这一问题。

现在按已确定的对齐，以最多 64 位的整数单元承载连续原始字节，余数仍用字节表示。整数单元不赋予 payload 的浮点、Boolean、tag 或 niche 有效性；完整 size、alignment、padding、managed leaf 偏移及 AS1 指针保持。实现只消费已有布局与 scan，不增加分析框架、runtime 路径或诊断代码。合同见实现 spec §2.10。

所有 profile 默认使用相同存储；release 复用现有 SROA、向量化与调用点内联。LIR 物理 ABI、跨 Cone 传值和 `.slib` 布局编码保持；重新编译含相关正文的 Cone 才能获得生成代码收益。

测量以包含 GC 地址重定位修复的 `42504b578` 为基线，保持旧 ArrayList API，与仅改变 LLVM 存储的版本对照。独立的 ArrayList 快照成员不计入本项收益。三个版本共用原 runtime；普通 release 计时与 GC 统计分开，原始记录在仓库外 `scoop-performance-results/2026-10-26/array-list-snapshots/final`。

ARM64 的 `lambdas` 主函数从 3,667 减到 1,566 条指令，栈帧从 1,136 B 减到 240 B；原有 240 条 `ld1.b` 与 64 条 `tbl.16b` 静态指令消失，剩余掩码复制使用整字读取。这是最终机器码的静态统计，不是每轮执行次数或周期推算。该程序及快照、strmap、dispatch、`List<Long>` 对照的 MIR／LIR 完全相同，变化发生在 LLVM 表示及优化中。

GNU／musl 的主函数均从 5,236 减到 1,580 条指令，原 317 条 `movzbl` 和大量 unpack／shift 拼装消失。三目标九个程序的 MIR／LIR 都保持相同；实际检查最终机器码，而非仅以存在向量 IR 作为结果。

两机格式化、相关 release all-targets Clippy 和各两项 codegen 回归通过。回归覆盖两种目标的完整大小、1／2／4／8／16 对齐、引用偏移，以及实际 LLVM 存储类型的整字向量复制。Darwin ARM64、Linux GNU／musl 均通过两项 core 位级测试、反向 debug／release provider-consumer ABI 专测及两个 profile 的 GC 专测；检查 padding、浮点特殊位模式、ZST、接口／可空值、调用与实际搬迁。没有运行完整 fixture 集。

2026-10-26，M3 Ultra／LLVM 22.1.8 与 i7-12700H／LLVM 22.1.2 实机对照。Linux 固定 CPU 4；一次预热、五轮正反序交替，下面是耗时中位数变化，负值为降低。

四个末尾对照的二进制分别逐字节相同，其时差不属于生成代码收益。ARM64 接口数组的一次定向复核为 0.124712→0.124749 s。musl 快照／dispatch／`List<Long>` 的短负载复核仍分别增加约 7.19%／5.40%／9.95%，等长启动路径没有消除差异；sum／get 的热路径指令及根操作保持，仅静态 phase 地址变化，尚未闭合布局与装载因素。同一路径覆盖复制后启动的额外实验连同字节 class 对照也偏离约 39%，不能用于替换主对照或宣称回退消失，原始结果全部保留。

九个程序的分配字节、minor／full 次数与根扫描量保持；trees 的少量搬迁字节差异也发生在相同二进制之间。lambdas 的 text 分别减少 11,368／26,176／26,112 B，完整文件减少 16,512／24,576／24,576 B；其余受影响程序 text 减少 484～7,488 B，全部完整文件均未增加。core／test 库大小保持，std／json 缩小不超过 0.032%。

一次预热、三轮独立 consumer 目标目录的冷构建中，lambdas 墙钟变化为 −1.76%／−3.47%／−3.39%，快照为 −3.91%／+0.14%／−1.52%；CPU 变化 −12.39%～+0.45%，峰值 RSS 最大增加 0.13%。本项采用统一默认表示，依据是通用字节拼装已消除、三目标 lambdas 获益且代码／编译成本降低；上述短负载回退仍作为限制保留，没有按程序名称调整布局。
