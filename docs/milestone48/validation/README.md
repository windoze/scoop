# M48 验证结果概要

本目录只保存验证结论、范围和必要的失败／补验说明。原始日志、trace、逐用例／逐轮报告、进程样本和一次性验收脚本保存在仓库外，不纳入版本控制。历史分批文档记录当时结果；M48 最终结果以本文、[验收对应表](../ACCEPTANCE.md)和[性能记录](../PERFORMANCE.md)为准。

## 最终功能验收

验证对象为 `9edf9060` 之后的全部集中清理和 MORE-CLEANUP 改动。所有本机修改与完整复验结束后，才同步到 nuc12 统一验证 GNU／musl。两个平台使用相同编译器、runtime 和 sysroot 源码；下述定向补验仅修正测试期望或 consumer 源码。

| 范围 | 通过 | 不适用 | 验证方式 |
| --- | ---: | ---: | --- |
| Darwin Rust | 5,302 | — | 一轮完整执行，再分别补验两条修正旧期望的测试 |
| Linux Rust | 5,338 | — | 一轮完整执行，零失败、零忽略 |
| Darwin 正式 CLI | 4,089 | 18 | 一轮完整执行，再补验三个新增 consumer |
| GNU 正式 CLI | 4,078 | 29 | 一轮完整执行，零失败，无补验 |
| musl 正式 CLI | 4,074 | 33 | 一轮完整执行，零失败，无补验 |
| fixture runner 公共规则 | 两机各 50 | — | 各执行一次 |

两机整仓 Rust 格式检查、Clippy 和 release 工具构建通过；本机 Python 使用 Ruff 0.16.10 格式化及 lint。正式 CLI 每个目标均发现并选择全部 4,107 个用例，不适用项按各自目标声明排除，不计为通过。

本机 Rust 首轮的两条失败分别为 M12 calling-convention 诊断文字和旧 profile 期望；更新期望后逐条通过。CLI 首轮的三个新增 consumer 分别修正 UInt8 显式转换、公开对象／接口的访问及实际 descriptor 调用；未修改 provider 可见性，三个用例补验通过。其他已通过部分没有重跑。

## 验收耗时与覆盖

| 目标 | 并发数 | 完整首轮墙钟 | variants | 进程调用 | stage／plan golden |
| --- | ---: | ---: | ---: | ---: | ---: |
| Darwin | 10 | 1,688.1 秒（28.1 分钟） | 4,613 | 16,356 | 88 |
| GNU | 12 | 2,103.0 秒（35.1 分钟） | 4,598 | 16,183 | 70 |
| musl | 12 | 2,106.5 秒（35.1 分钟） | 4,594 | 16,149 | 70 |

Darwin 的墙钟只含完整首轮，三个 consumer 的补验另计；表中覆盖数包含最终通过的补验。同一 M4 Pro、10 并发下，用例累计耗时由追加清理前的 32,324.5 秒降至 16,770.0 秒，减少 48.1%；进程调用由 17,040 降至 16,356，减少 684 次，variants 与 golden 数量保持。累计耗时是并行用例各自耗时之和；此前未记录可靠的完整墙钟，因此不报告墙钟加速比例。

Darwin 主机为 M4 Pro、14 个逻辑 CPU、64 GiB 内存，LLVM 22.1.8。nuc12 为 x86_64 Linux、20 个逻辑 CPU、约 64 GiB 内存，Rust 1.99.0、LLVM 22.1.2、GCC 15.2.0；两个 Linux 目标复用同一批 release 工具及 Cargo 增量缓存。需要配套编译器的 Rust linker 测试直接使用本批 release scoopc。

## 性能与调用观察

原版本和最终实现已在同一 M4 Pro 分别完成 55 次构建：五个场景各五组冷／暖，native 另加五次头文件更新。生成程序均实际运行并检查输出，完整时间与 RSS 口径见[性能记录](../PERFORMANCE.md)。Linux [最终调用及按需读取观察](final-io.md)全部通过：GNU 55 次、musl 5 次构建；全部暖构建零编译／链接、零受检内容打开、零 rename。下游依赖一次打开、无重叠读取，4,207 个机器 member 未读。trace 耗时不参与 Darwin 性能对照。

本批结束后清理 Darwin fixture 工作目录约 38.3 GiB；Linux GNU／musl 工作目录在各自完整通过后清理，另清理此前中断且已结束的工作目录约 39.6 GiB。两机近期仍复用的 Rust／release 增量缓存保留。
