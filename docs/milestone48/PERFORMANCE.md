# M48 最终性能测量

同机对照：Apple M4 Pro，14 个逻辑 CPU，64 GiB 内存。原版本为未修改的 `6571bb4a`；当前版本为 `9edf9060` 加全部集中清理及 MORE-CLEANUP 改动。两端均使用 release Scoop 工具、debug Scoop profile 和同一测量脚本，各 55 次实际构建，生成程序均运行并检查输出。旧版本已在同机完成测量，本轮直接复用其原始记录。

| 场景／阶段 | 原版本中位数（范围，秒） | M48 中位数（范围，秒） | 时间减少 | 原版本／M48 抽样 RSS 中位数（MiB） |
| --- | --- | --- | --- | --- |

每个场景五组独立冷／暖命令，native 另有五次实际头文件更新。当前全部暖构建均为零 compiler build child；头文件变化只编译一个受影响 Cone。统一 Linux 验收后的[实际调用与 I/O 观察](validation/final-io.md)已完成：GNU 55 次构建、musl 5 次代表构建全部通过，暖构建没有编译、预处理或链接。精确调用由 execve 记录取得，进程抽样不充当计数。

冷缓存是新的 Scoop 缓存，未刷新 OS 文件缓存。RSS 为 `ps` 抽样的同时存活后代之和，每轮后等待约 20 ms；暖构建时间受此测量粒度影响，RSS 不代表未采到的瞬时峰值。比较反映 M48 整批改变，不能拆成单项优化贡献或承诺固定加速幅度。

历史早期基线标注为 M3 Ultra，本表只使用确认硬件后的 M4 Pro 同机数据；历史记录继续保留，不混用其数值。
